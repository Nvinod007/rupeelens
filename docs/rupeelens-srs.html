🖥️ Front-end (apps/rupeelens-fe · Vercel)

Nx monorepo · Next.js App Router · Tailwind · mic + Web Speech API · SSE client for streamed draft JSON. Ship the paste-key page and a minimal transaction list first; wire voice second.

pnpm nx g @nx/next:application rupeelens-fe --directory=apps/rupeelens-fe --appDir=true --style=tailwind --linter=eslint --unitTestRunner=jest --e2eTestRunner=none
pnpm nx dev rupeelens-fe

Create these files next (order matters):

src/app/settings/byok/page.tsx → src/app/page.tsx → src/lib/speech/useWebSpeech.ts → src/lib/api/sseParseDraft.ts → src/components/TransactionList.tsx
cp apps/rupeelens-fe/.env.example apps/rupeelens-fe/.env.local

BYOK UI: link to aistudio.google.com/api-keys, masked input, POST /api/settings/byok (no “Test connection” — first parse validates). List page: GET /api/transactions (empty state OK). Vercel project root = apps/rupeelens-fe.

⚙️ Back-end (apps/rupeelens-api · Fly.io free)

NestJS · Gemini gemini-2.5-flash-lite streaming SSE proxy · Supabase (Postgres, free tier) · AES-GCM for BYOK at rest (key-vault.service.ts). No local LLM on 512 MB-class VMs.

pnpm nx g @nx/nest:application --name=rupeelens-api --directory=apps/rupeelens-api --linter=eslint --unitTestRunner=jest --e2eTestRunner=none
pnpm add @supabase/supabase-js pnpm nx serve rupeelens-api
src/parse/parse.controller.ts → src/parse/parse.service.ts → src/transactions/transactions.controller.ts → src/crypto/key-vault.service.ts → supabase/migrations/*.sql
cp apps/rupeelens-api/.env.example apps/rupeelens-api/.env

Fly: fly launch / fly deploy from API app · global prefix api · CORS https://rupeelens.appkits.in + localhost.
