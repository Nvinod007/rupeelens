Deployment commands

Frontend on Vercel, API on Northflank, domain on Hostinger. Run from the repo root. Never commit secrets.

1. Install

pnpm install --frozen-lockfile

2. Local checks (Nx)

pnpm nx run-many -t lint
pnpm nx run-many -t test
pnpm nx run-many -t build

# only what your branch changed
pnpm nx affected -t lint test build

3. Frontend → Vercel

npm i -g vercel
vercel login
vercel link                      # project root = repo root (uses vercel.json)
vercel env add NEXT_PUBLIC_API_URL production
vercel env add NEXT_PUBLIC_SUPABASE_URL production
vercel env add NEXT_PUBLIC_SUPABASE_ANON_KEY production
vercel --prod

4. API → Northflank (London, free Sandbox)

# Set once in the Northflank UI (no CLI needed):
#   Service type: Combined (build + deploy) from GitHub repo, branch main, CI/CD on
#   Build: Dockerfile  /apps/rupeelens-api/Dockerfile   context  /
#   Port: 8080 (HTTP, public)   Health check: /api/health
#   Runtime variables:
#     NODE_ENV=production  PORT=8080  TRANSACTIONS_STORAGE=supabase
#     KEY_ENCRYPTION_SECRET=...  SUPABASE_URL=...  SUPABASE_SERVICE_ROLE_KEY=...
#     GEMINI_MODEL=...
#     CORS_ORIGINS=https://rupeelens.appkits.in,https://rupeelens-gules.vercel.app

# Every push to main rebuilds and redeploys automatically.
curl https://api-rupeelens.appkits.in/api/health

5. Domain DNS (Hostinger)

# Frontend (Vercel)
#   CNAME  rupeelens      →  target Vercel prints (e.g. cname.vercel-dns.com)

# API (Northflank)
#   CNAME  api-rupeelens  →  api-rupeelens.appkits.in.<id>.dns.northflank.app
#   TXT    verify-api...  →  value Northflank prints (keep it; proves ownership)
#   Certificate is issued and renewed automatically.

#   Site URL:      https://rupeelens.appkits.in
#   Redirect URL:  https://rupeelens.appkits.in/auth/callback
